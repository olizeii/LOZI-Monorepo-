# Lozi-Client

Web-App im Vollbild auf jedem Bildschirm: Avatar (schläft, hört zu, denkt, spricht) und Inhalte von Lozi-Core.
Protokoll: `docs/display-protokoll.md`. Geplant: Lozi-Core liefert den Client mit aus, Aufruf z. B.
`http://<lozi-core>:8765/client/?display=tv`.

Läuft auf: Chromecast mit Google TV (Fully Kiosk Browser), Ubuntu-PCs (Browser im Kiosk-Modus), Boxautomat.

**Noch nicht gebaut.** Nächster Schritt in Phase 1, mit den Design-Skills (keine typische „KI-Design“-Optik).
