# Module

Ein Ordner pro Feature. Jedes Modul hat ein eigenes README mit seinen Tools (→ `docs/tool-vertraege.md`),
MQTT-Topics und Tests. Geplant: `licht`, `tv`, `beamer`, `kameras`, `dart`, `audio`, `gaming`,
`boxautomat-bridge`, `einkaufsliste`.

Was Home Assistant mit einer fertigen Integration kann (Shelly, WLED, Bravia/Android TV, Music Assistant),
bekommt **kein** eigenes Modul, sondern nur Konfiguration in `homeassistant/`.
